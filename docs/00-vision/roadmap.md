# Roadmap

> Hoja de ruta provisional. Se actualizará después de validar el flujo real de trabajo con la administradora.

## Fase 1 — Núcleo Contable (actual)

Módulos: Comunidades, Propietarios, Recibos (mayor dual), Proveedores, Deudores + Exportación CSV.
Stack: Next.js + TypeScript + datos mock. Sin backend real.

## Fase 2 — Fiscalidad y Reporting

Filtro modelo 347, comparativos interanuales y presupuesto vs ejecutado.

## Fase 3 — Automatización Operativa

Recordatorios automáticos de cuotas, correspondencia masiva personalizada, envío de emails integrado.

## Fase 4 — Gestión Integral del Edificio

Incidencias, siniestros, obras, mantenimientos, contratos, inventario, inspecciones.

---

> ⏸️ La **Fase 3 del plano técnico** (apps/, packages/, database/, scripts/) se activa después de la demo con la administradora, cuando tengamos validado el MVP real, el modelo de datos y los módulos prioritarios.
