# Diseño

## Contexto

El diseño inicial de Fincas Pro sirve como referencia visual para el prototype.

No es todavía una especificación cerrada del producto.

## Dirección visual

- Estilo sobrio.
- Profesional.
- Denso, sin ser confuso.
- Orientado a trabajo diario.
- Prioridad a velocidad y claridad.

## Patrones principales

- Navegación lateral.
- Tablas como núcleo de la experiencia.
- Filtros visibles.
- Búsqueda rápida.
- Badges de estado.
- Acciones claras por fila o por listado.
- Jerarquía visual simple.

## Nota sobre el diseño 06-04

El diseño 06-04 refuerza una dirección más operativa: rendimiento primero, núcleo contable visible, filtros claros, tablas densas y señales rápidas para estados importantes.

También introduce la idea de KPIs o métricas visuales, pero esos KPIs no deben tratarse como definitivos hasta validar el flujo real con la usuaria.

## Uso de diseños generados

- No copiar HTML de Stitch tal cual.
- Limpiar estructura antes de llevarla al proyecto.
- Convertir diseños en componentes reutilizables.
- Separar datos mock de componentes de UI.
- Evitar estilos duplicados o clases sin criterio.
- Mantener nombres claros y relacionados con el dominio.

## Criterio de calidad

Una pantalla debe ayudar a encontrar información rápido.

Si se ve bonita pero no mejora búsqueda, filtros o lectura de datos, todavía no está validada.

## Antes de implementar una pantalla

- Confirmar que la pantalla fue pedida.
- Confirmar que pertenece al alcance actual.
- Definir qué datos mock necesita.
- Definir qué filtros muestra.
- Definir qué tarea real ayuda a validar.
